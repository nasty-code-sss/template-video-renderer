# Что делать, когда упало

## Команда завершается с ошибкой и файла нет

Так и задумано: проект не оставляет битый mp4. Смотрим текст ошибки, он называет причину.

| Ошибка | Что значит | Что делать |
|---|---|---|
| `InvalidProjectDocumentError: scene 2: field 'title' ...` | в сцене нет обязательного поля | поправить JSON, номер сцены назван в тексте |
| `InvalidProjectDocumentError: ... was not found` | картинка или файл проекта не найдены | путь считается от папки файла проекта, проверить его |
| `MissingSettingError: configuration key ...` | в конфиге нет ключа | добавить ключ в `config/base.yml` |
| `MissingSettingError: APP_ENV=...` | контур назван неверно | допустимы только `dev`, `stage`, `prod` |
| `EncodingFailedError: ffmpeg failed: ...` | FFmpeg отказался кодировать | последние строки его вывода идут в том же сообщении |
| `SceneAssetMissingError: font ... could not be opened` | шрифта нет по указанному пути | поправить `font_path` в `config/base.yml` |
| `InvalidProjectDocumentError: projects directory ... holds no *.json files` | папка для `batch` пуста или файлы лежат во вложенных папках | `batch` берёт `*.json` только с верхнего уровня папки |

## Пачка собралась не целиком

`rendered 2 of 3 projects` и код возврата 1 значат, что часть роликов готова,
а часть упала. Собранные файлы лежат на месте, причина каждого падения напечатана
строкой с именем проекта. Чинится это правкой конкретного JSON, перезапускать всю
пачку не обязательно: `render` соберёт один ролик.

## Рендер идёт и не заканчивается

Сначала посмотреть на строки `rendered frame N of M`: если номер растёт, работа идёт,
просто ролик длинный. Ориентир с машины разработки: 312 кадров 1080p занимают около
22 секунд.

Если номер не растёт и процесс висит, проверить, жив ли FFmpeg:

```
Get-Process ffmpeg
```

Такой симптом уже был 16.09.2026: FFmpeg писал диагностику в переполнившийся канал,
переставал забирать кадры, и оба процесса вставали намертво. Лечится это не перезапуском,
а тем, что его вывод пишется во временный файл (`FfmpegVideoEncoder`). Если симптом
вернулся, смотреть надо туда.

## FFmpeg не найден

```
FileNotFoundError: [WinError 2]
```

FFmpeg не в `PATH`. Либо добавить его в `PATH`, либо указать путь явно:

```
$env:FFMPEG_BINARY = "C:\path\to\ffmpeg.exe"
```

## Ролик собрался, но выглядит не так

Проверять надо кадром, а не догадкой:

```
ffmpeg -y -ss 2.0 -i out\demo.mp4 -frames:v 1 frame.png
```

Дальше смотреть глазами. Текст не появился это тайминги (`title_delay_seconds`
больше длительности сцены), текст не влезает это размер шрифта в `typography`.

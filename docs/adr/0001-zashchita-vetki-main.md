# 0001. Ветка main не защищена настройками GitHub

Дата: 16.09.2026
Статус: принято, требует решения Насти

## Контекст

Стандарт (`architecture.md`, раздел 3.3) требует защиты `main`: запрет прямого пуша,
обязательный pull request, запрет force push.

При попытке включить защиту через API GitHub ответил `403`:

```
Upgrade to GitHub Pro or make this repository public to enable this feature.
```

Защита веток на приватных репозиториях входит в платный план. Репозиторий заведён
приватным по умолчанию, как требует раздел 3.1.

## Решение

Пока защита не включена. Порядок работы соблюдается вручную: код идёт ветками
`feature/`, вливается через pull request, прямых коммитов в `main` нет, кроме первого
коммита с каркасом, которым репозиторий заводится.

## Что это меняет

Правило держится дисциплиной, а не настройкой. Ошибочный прямой пуш в `main`
технически возможен и никем не будет остановлен.

## Как снять отступление

Два пути, выбор за Настей:

1. Сделать репозиторий публичным. Защита включается бесплатно, а для кейса
   в портфолио открытый код это плюс: его можно показать заказчику ссылкой.
   Заказчикова в репозитории ничего нет, он написан с нуля.
2. Оставить приватным и принять отступление до появления платного плана.

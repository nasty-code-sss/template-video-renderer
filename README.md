# template-video-renderer

Собирает готовый видеофайл из описания сцен и шаблона оформления, без ручного монтажа.

На вход подаётся JSON со сценами (заголовок, подпись, картинка) и YAML-шаблон
с оформлением (шрифты, цвета, тайминги, переходы). На выходе получается mp4.

Один шаблон плюс сто строк данных дают сто роликов: карточки товаров, анонсы,
обзоры, вертикальные шортсы под соцсети.

## Зачем

Ручной монтаж однотипных роликов стоит одинаково дорого за каждый ролик.
Здесь стоимость платится один раз за шаблон, а дальше ролики считаются пачкой
и выглядят одинаково аккуратно, потому что оформление задано не рукой, а конфигом.

## Быстрый старт

```
pip install -e .
python -m template_video_renderer render --project examples/demo.json --output out/demo.mp4
```

Формат кадра, шрифты, цвета, длительности и переходы берутся из `config/base.yml`
и шаблона проекта. В коде ничего из этого не зашито.

## Пачкой

```
python -m template_video_renderer batch --projects examples --output-dir out
```

Берёт из папки все `*.json` по алфавиту и складывает рядом столько же mp4:
имя ролика повторяет имя файла проекта. Один упавший проект остальные не роняет,
его причина печатается отдельной строкой, а в конце идёт итог `rendered N of M projects`.
Код возврата 1, если упал хотя бы один ролик, поэтому в скрипте видно, что не всё собралось.

## Требования

- Python 3.12
- FFmpeg в `PATH` (проверено на 8.1.2)
